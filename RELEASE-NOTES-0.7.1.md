# InkVault 0.7.1

**Copy and paste works again.**

The last release turned off text selection in long books to avoid a freeze that comes from iOS itself. The freeze is real, but taking away copy and paste to avoid it was the wrong call to make for you, and it should not have been made silently.

Selection is back everywhere. If you would rather have the speed than the selection in very long books, there is now a switch for it in Settings under "Reading long books", which explains exactly what each choice costs.

The reader's Copy button stays, for every document. It copies the page you are on straight from what InkVault read when it indexed the book, which is instant.
