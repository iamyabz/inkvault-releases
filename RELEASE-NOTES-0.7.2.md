# InkVault 0.7.2

**You can select across a whole page now.**

Copying from a document's text only ever gave you one paragraph, because each paragraph was a separate piece of text as far as the system was concerned — selection could not cross between them. The page is now a single piece of text, with the normal selection handles, magnifier and menu, and you can drag across as much of it as you like.

This also happens to be the fast way to take text out of a very long book: it comes from what InkVault read when it indexed the document, so it never triggers the pause that selecting on the page image can cause.

**The reader's tabs are now Page, Summary, Text** — the page first, since it is the document itself.
