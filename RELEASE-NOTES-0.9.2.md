# 0.9.2

## The contents list was a page late on every chapter

A chapter's opening page is its title page, and a title page carries no running
head — the head starts on the page after it. The contents were built from the
first page carrying the head, so every entry pointed at the chapter's second
page. In Davidson's, "Good medical practice" is on page 22 and the list said 23.

## The Mac was guessing at contents it did not need to guess

It never looked at the book's own table of contents. Where a PDF carries one,
the Mac now uses it, with the publisher's own titles and pages, exactly as the
iPad already did.

## Contents and annotations no longer need a second open

The contents were built the instant the window appeared, which on a large
library is before the library has finished loading — so the list came up empty
and closing the document and opening it again "fixed" it. It now waits.
