# InkVault 0.9.67

## USMLE-style quizzes (Mac, iPhone and iPad)

When you type a board exam as the quiz style (USMLE, Step 1/2/3, NBME shelf,
COMLEX), questions now follow the way real board items are written:

- **One patient, one question.** A full clinical vignette that never names the
  diagnosis, organism or drug you are meant to work out, so you have to
  recognise it first.
- **No giveaways.** The question no longer tells you the Gram stain, the drug
  class or which toxin a test found.
- **Real answer choices.** Short options of one kind, where every wrong answer
  is a true fact about something else, not an invented one.
- **No EXCEPT questions,** and no two questions testing the same point.
- **Up to date.** Treatments that current guidelines no longer recommend are
  not used as the correct answer.

## Also

- Short material, such as a single lecture, is now written in one pass, so a
  quiz no longer repeats the same point several times.
