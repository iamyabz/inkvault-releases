# InkVault 0.9.63

- **Files you add inside a folder now stay in that folder.** Dragging files
  from Finder into a folder, or using Add from inside one, used to put
  recordings, videos and spreadsheets at the top of the library, so they only
  showed up in All Files. Every kind of file now lands in the folder you were
  in, including nested folders, even if you move to another folder while it
  imports.

Includes the transcription fixes from 0.9.61 and 0.9.62.
