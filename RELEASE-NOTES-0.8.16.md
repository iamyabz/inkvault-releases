# InkVault 0.8.16

**Asking several questions about the same book now costs a fraction of what it did — and the answers come from better pages.**

When you ask about a long document, the app sends the AI the pages that bear on your question. Measured against a set of 51 questions with known answers, the right page is now included **84% of the time, against 51% before** — while sending fewer characters, not more.

**Repeated questions about the same document no longer re-send it.** The evidence is uploaded once and reused, so the second and tenth questions cost a fraction of the first. The AI sees exactly the same material either way.

If anything goes wrong with that, the question is simply asked the old way — nothing fails because a saving could not be made.
