# InkVault 0.5.13

**When Gemini turns you away, InkVault now tells you why.**

Indexing a large book can run an API key into a limit — a spend cap you set, the free tier's daily allowance, or a short pause because requests came too quickly. Google reports all three the same way, and InkVault treated all three as the last one: "it will settle on its own; try again shortly". For a spend cap that is simply untrue, and it sent people back to the same wall every few minutes.

Now, where Google says which limit was hit, InkVault says so too — the daily allowance and when it resets, or how long to wait when it names a wait. Where Google doesn't say, InkVault stops guessing and points at the spend limit and quota page for your project instead of promising a recovery it can't predict.

**Also:** the app kept two separate copies of its error messages, and the one you actually see was the older one — so the clearer explanation added for retired models never reached the screen. There is one now.

Imports also pace their requests on iPhone and iPad, as they already did on the Mac.
