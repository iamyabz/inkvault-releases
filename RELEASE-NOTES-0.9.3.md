# 0.9.3

## Chapters are numbered

The contents list now numbers the chapters, so "chapter 12" is something you can
look up rather than count to. Only where the list really is a straight run of
chapters — a nested outline keeps the publisher's own structure, because there
an entry's position is not its number.

## Adding a blank page no longer hides behind the pen

Slipping blank paper into a book was in the add menu, and that menu only
appeared once markup was switched on — so if you were reading, it was not there.
Paper is not ink: it is somewhere to write that did not exist before, and it is
now offered whether or not the pen is out.
