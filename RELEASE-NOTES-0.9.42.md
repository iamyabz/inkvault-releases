# 0.9.42

## Importing a shared file says what it is doing

Opening a `.inkvault` looked like nothing had happened until the documents
appeared some seconds later. It now tells you it is reading the file, and then
that it is importing — which matters most for a shared folder, where the second
half is copying gigabytes.

## iPhone and iPad

Carries 0.9.41's fix for the opening animation, which could keep playing and
never hand over to your library.
