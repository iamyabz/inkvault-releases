# InkVault 0.7.3

**A long book no longer hands the whole thing to iOS at once.**

The freeze when selecting text in very long books comes from iOS analysing pages it has already been given searchable text for. There is no way to switch that off — so instead, InkVault now shows iOS only the part of the book you are actually reading, sliding that window along as you go.

Everything works the way it did. Selection, the page numbers, contents, the slider, the thumbnails, pen marks, Ask AI — all still address the real book. Scrolling is unchanged.

If this is the cause, the pause is gone. If it is not, it will be clear quickly and nothing has been given up to find out.
