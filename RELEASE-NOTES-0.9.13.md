# 0.9.13

## A book that kept asking iCloud for annotations that were never there

One release wrote down that a device had published annotations when it had only
recorded an intention to. Every other device has been asking for those ever
since, on every open, and the server has been answering "no such thing" in
silence.

Those claims are now recognised for what they are and dropped, and only those —
annotations that merely have not arrived yet are still waited for. The device
that really does have marks announces itself again the next time it publishes.
