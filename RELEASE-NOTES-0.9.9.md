# 0.9.9

## Two messages that were not telling the truth

When a book is too long to embed a selectable text layer, the notice said its
text would not be selectable "in other PDF apps". It is not selectable here
either — the readers select through the same layer. Searching and Ask AI are
genuinely unaffected, because those read the app's own index and never touch the
file. The notice now says all of that.

"Share Original" in the reader did not share the original. Importing replaces
the file with the searchable copy, so there is no original to share; it is now
called "Share PDF".
