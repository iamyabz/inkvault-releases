# InkVault 0.5.3

**The iCloud switch, on the Mac.**

0.5.2 introduced a switch on every document that decides whether its file is kept in iCloud — and it shipped on iPhone and iPad only. The Mac's list showed the sizes and no way to act on them. It is there now, in Settings ▸ Index & Privacy ▸ Documents by size, beside each file.

As before: the switch is only about the file itself. Every document's text and search index sync always, so a textbook you keep on this Mac still turns up when you search from your phone and can still be asked questions there. Turn one off after it has uploaded and it comes back out of iCloud, so the space is genuinely returned.
