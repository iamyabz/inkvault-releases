# 0.9.39

## iPhone and iPad open with an animation

Opening InkVault used to sit on a blank screen while the library loaded. Now a
drop of ink falls, lands, and the keyhole opens through it — and the app appears
the moment it is ready, so the wait is covered rather than displayed. It fades
in from whatever the screen already was, so there is no flash on the way in, in
light mode or dark. If you have Reduce Motion turned on you get the mark without
the movement.

## Mac

No changes in this release; 0.9.38's fixes for shared files are unchanged.
