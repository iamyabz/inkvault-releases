# InkVault 0.7.4

**The fix now covers both readers.**

Selecting text in a very long book is instant again — that landed last release for full screen, and this one brings it to the reader you see beside your notes, which had exactly the same problem waiting in it.

Also fixed along the way: sharing a marked-up copy of a very long book would have shared only the part you were reading. It shares the whole book.
