# InkVault 0.8.8

**Tape peels, the tape tool no longer takes over the screen, and objects stay put while you read.**

**Tape now peels when you tap it.** It always did — and then re-stuck itself in the same instant, because the peeled state was never saved.

**Drawing tape works like it does in your notebooks.** Arm "Draw a tape shape" and draw it with the pen: a box, a rounded strip or a circle. The previous version put a full-screen layer over everything, which left no controls and no way out.

**Sticky notes and tape stay where you put them while reading.** Dragging and resizing now belong to the pen being out, and so does adding them. Tapping still works either way — tape peels and cards open while you read, which is the point of covering an answer.

**A put-away sticky no longer disappears.** Its tab was sitting half off the edge of the page.

**Lighter on memory in a long session.** Several things grew for as long as a book stayed open, including one decoded copy of the handwriting for every page you had scrolled past.
