# InkVault 0.9.64

- **Shift-Return starts a new line in chat.** In document, recording and page
  chat and the quiz tutor, Return sends your message and Shift-Return now
  starts a new line where your cursor is, so you can write longer questions in
  paragraphs. It used to send the message instead. While you are typing in
  Japanese, Chinese or Korean, Return finishes the character you are composing
  rather than sending.

Includes 0.9.63's fix for files added inside a folder.
